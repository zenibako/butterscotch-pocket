# v0.7.6 — battle HUD and Forest sentry optimizations

## Changes since v0.7.5

- **Deltarune Chapter 1:** reduces Speed-mode battle HUD rendering work by caching exact filtered button pixels, with a 32 KiB storage limit. Existing HUD sharpening and colors are preserved.
- **Deltarune Chapter 1:** reduces work in Forest sentry rooms through guarded native statue updates and faster translucent overlay fills.
- **Both games:** adds positional Pocket button prompts and exposes the built-in controls through the games' controller APIs.
- **Memories:** accepts compatible older metadata-and-code identities while retaining game, checksum and resource validation. Use the original game data; this does not make every historical Memory compatible.

## Installation and compatibility

Download [butterscotch-pocket.zip](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.6/butterscotch-pocket.zip). Import this core ZIP in Pocket Sync, or extract it into the SD-card root, merging `Cores`, `Assets` and `Platforms` and replacing matching files.

The package includes both game programs and the matched runtime. Supply your own **Undertale v1.08** or **Deltarune Chapter 1** data. Existing prepared data does not need conversion for this update. See the [game-data guide](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.6/GAME-DATA.md) for new installations. The release also includes the Pocket Sync plugin, six native preparation bundles, WASI CLI, source archives, licenses and provenance.

Back up your card before updating. Keep existing game files, `/Saves/butterscotch/common/` and Memories. No commercial game data or player saves are included. Ordinary progress saves are separate from Memories and power-button sleep.

## Verification and known limitations

- The core changes have automated cache, rendering, audio and snapshot regression coverage. Covered desktop scenes preserve pixels and PCM in both rendering modes. Complete distribution CI gates both public game builds, native tools, plugin/C-reference tests, packaging and checksums.
- An isolated os25 simulation reduced a warm 15-icon raster pass from **9.24 ms to 1.24 ms**. This is a component measurement, not a whole-frame or physical Pocket FPS result.
- The earlier sentry/legacy-Memory candidate received a successful qualitative Pocket report. **This release's HUD cache and final public package have not yet been tested on Pocket.**
- **Known issue:** Deltarune battle Memories can load with party and enemy sprites missing. It reproduces before and after the HUD cache; this release does not fix it. See [issue #13](https://github.com/zenibako/butterscotch-pocket/issues/13). Covered dialogue and field Memory restore controls pass.
- Memories and sleep/wake remain experimental and scene-dependent. Check **Select > Debug > Save-state status** before sleeping. Public programs omit private compile-time game fingerprints, so Memories from private test builds may be incompatible. Normal progress saves remain separate.
- The unchanged 100 MHz os25 runtime has **−0.777 ns worst setup slack** in its slow 85°C timing corner. It misses that timing target; software tests do not establish FPGA timing closure.
