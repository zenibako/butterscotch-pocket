# v0.7.14 — smoother Snowdin Town and easier setup

Undertale v1.08 and experimental Deltarune Chapter 1 remain the supported games.

## What's new

- **Snowdin Town runs much smoother.** Walking around town takes about half as long per frame as before, and coming back into town from a nearby room pauses about half as long. [PR #137](https://github.com/zenibako/butterscotch-pocket/pull/137) · [PR #138](https://github.com/zenibako/butterscotch-pocket/pull/138) · [PR #139](https://github.com/zenibako/butterscotch-pocket/pull/139)
- **Deltarune is a little quicker too.** Large tiled rooms, including the forest dancer room, stall less when you enter them, and the castle town yard runs faster. [PR #139](https://github.com/zenibako/butterscotch-pocket/pull/139)
- **Easier setup.** One install guide covers both Pocket Sync and copying by hand, and if game files are missing, the error screen now explains how to build them, with a QR code to the steps. [PR #140](https://github.com/zenibako/butterscotch-pocket/pull/140)

## Installing and known issues

Import the core ZIP in Pocket Sync, or extract it to the root of your SD card, merging the `Cores`, `Assets` and `Platforms` folders. Existing prepared game data and saves can be reused.

Some heavy scenes still slow down. The first time you enter Snowdin Town after starting the game there is still a short pause while its graphics load. Memories and sleep/wake remain experimental; Deltarune battle Memories can restore with missing party or enemy sprites. [Issue #61](https://github.com/zenibako/butterscotch-pocket/issues/61)

Testing: CI builds and checks both games and the tools. The Snowdin Town and Deltarune changes were measured on a Pocket in benchmark builds.
