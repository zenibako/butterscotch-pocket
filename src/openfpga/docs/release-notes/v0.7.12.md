# v0.7.12 — sharper battles and fewer loading hitches

Undertale v1.08 and experimental Deltarune Chapter 1 remain the supported games.

## What's new

- **Sharper Undertale battles in Speed mode.** Most battles now draw at 640×480; heavier fights keep 320×240. Accuracy mode also benefits from faster sprite drawing and screen fills. [PR #109](https://github.com/zenibako/butterscotch-pocket/pull/109)
- **Fewer mid-battle loading hitches.** Undertale loads battle textures during the encounter flash, reducing pauses when they first appear. Some loading stalls remain. [PR #110](https://github.com/zenibako/butterscotch-pocket/pull/110)
- **Smoother Photoshop Flowey pacing in Speed mode**, with attack cues retained. [PR #109](https://github.com/zenibako/butterscotch-pocket/pull/109)
- Finished benchmarks show a **QR code for the report**; press any button to switch between the code and log. [PR #107](https://github.com/zenibako/butterscotch-pocket/pull/107)
- GMS2 asset-layer tile drawing reuses cached tile runs. [PR #106](https://github.com/zenibako/butterscotch-pocket/pull/106)

## Installing and Memories

Import `butterscotch-pocket.zip` in Pocket Sync, or extract it to the root of your SD card, merging `Cores`, `Assets` and `Platforms`. Existing prepared game data and ordinary progress saves can be reused; no game-data conversion is required. [Game-data guide](https://github.com/zenibako/butterscotch-pocket/blob/main/src/openfpga/GAME-DATA.md)

The Memory format remains at revision 10. Compatibility with earlier Memories on this exact candidate is not yet physically verified. Memories and sleep/wake remain experimental; Deltarune battle Memories can restore with missing party or enemy sprites. [#61](https://github.com/zenibako/butterscotch-pocket/issues/61)

## Verification and limits

The merged changes have desktop frame comparisons for both games and Pocket battle-tour evidence. The exact release candidate still needs physical launch, progress-save, Memory and sleep/wake checks for both games. Automated packaging checks do not establish those results.

Heavy scenes can still slow down, including Asgore and other demanding battles. The SDK/runtime pins are unchanged. The experimental 100 MHz os25 runtime retains −0.777 ns worst setup slack in the slow 85°C corner.

The complete distribution includes both game programs, the Pocket Sync plugin, six native preparation bundles, WASI tools, source/license archives, provenance and `SHA256SUMS`. No commercial game data or saves are included.
