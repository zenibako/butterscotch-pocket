# v0.7.13 — full screen and a faster runtime

Undertale v1.08 and experimental Deltarune Chapter 1 remain the supported games.

## What's new

- **Full screen by default.** Games now fill the Pocket's 10:9 screen. Rooms that are too short for it stay at 4:3. Switch back any time with Select → Aspect Ratio. [PR #133](https://github.com/zenibako/butterscotch-pocket/pull/133)
- **Faster everywhere.** Butterscotch moves to a new openfpgaOS runtime with a faster CPU bitstream, about 12–14% faster in Undertale and Deltarune test runs. Sound is also louder than before. [PR #130](https://github.com/zenibako/butterscotch-pocket/pull/130) · [PR #132](https://github.com/zenibako/butterscotch-pocket/pull/132)
- **More Undertale battles look sharp in Speed mode.** 13 more battles, Flowey's first fight, the story battles and the quick hit scenes now draw at 640×480. [PR #134](https://github.com/zenibako/butterscotch-pocket/pull/134)
- **Deltarune's dancer room runs smoother.** The scissor dancers room in the forest is about a third faster. [PR #131](https://github.com/zenibako/butterscotch-pocket/pull/131)
- **A new loading bar.** A heart rides the loading bar, in each game's HP-bar colours. [PR #135](https://github.com/zenibako/butterscotch-pocket/pull/135)

## Installing and known issues

Import the core ZIP in Pocket Sync, or extract it to the root of your SD card, merging the `Cores`, `Assets` and `Platforms` folders. Existing prepared game data and saves can be reused.

Some heavy scenes still slow down, including Snowdin Town, which also pauses for a moment when you first enter it. Memories and sleep/wake remain experimental; Deltarune battle Memories can restore with missing party or enemy sprites. [Issue #61](https://github.com/zenibako/butterscotch-pocket/issues/61)
