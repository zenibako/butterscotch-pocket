# v0.7.8 — compact Pocket Sync plugin icon

- Fixes the oversized Butterscotch Game Data plugin row in Pocket Sync with a compact 40×40 icon, retaining the existing artwork.
- Adds shared release guidance maintained in [pocket-dev-tools](https://github.com/zenibako/pocket-dev-tools).

Install the complete [butterscotch-pocket.zip](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.8/butterscotch-pocket.zip), or update through Pocket Sync. Existing prepared Undertale v1.08 and Deltarune Chapter 1 data, ordinary saves and Memories remain in place. The game programs, runtime pins and Memory format are unchanged from v0.7.7.

The release includes both game programs, plugin/icon, native preparation tools, WASI CLI, source/license archives, provenance and SHA256SUMS. The icon fix is delivered by the new release asset; reloading Pocket Sync may be needed to refresh previously cached artwork.

Memories and sleep/wake retain their existing experimental status and compatibility limits. The Deltarune battle-sprite limitation in [issue #61](https://github.com/zenibako/butterscotch-pocket/issues/61) remains.
