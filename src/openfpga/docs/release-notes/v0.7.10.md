# v0.7.10 — faster battles on Pocket

This release speeds up Undertale battles, moves audio mixing to the Pocket hardware mixer, and adds a progress bar and clearer errors while games load. Undertale v1.08 and experimental Deltarune Chapter 1 remain the supported games.

## Changes since v0.7.9

- The renderer clears only the tiles it needs to redraw, reuses unchanged battle backdrops, and skips transparent gaps in half-size backdrops. Speed mode also caches the filtered battle buttons. [PR #84](https://github.com/zenibako/butterscotch-pocket/pull/84) · [PR #88](https://github.com/zenibako/butterscotch-pocket/pull/88) · [PR #89](https://github.com/zenibako/butterscotch-pocket/pull/89)
- Asgore's orange particles use a native update for matching game bytecode. Rotated sprites leave less of the framebuffer to clear on the next frame, and Mettaton EX's 50% black overlay uses a faster RGB555 blend. [PR #90](https://github.com/zenibako/butterscotch-pocket/pull/90)
- The hardware mixer resamples and mixes audio voices, leaving the CPU to decode them. Memories preserve queued hardware audio, and the software mixer remains available as a fallback. [PR #85](https://github.com/zenibako/butterscotch-pocket/pull/85)
- Game launches show a progress bar and explain common load failures. The port clears display buffers before video mode changes to prevent flashes of stale frames. [PR #86](https://github.com/zenibako/butterscotch-pocket/pull/86)
- The Undertale battle tour enters and exits fights through the game's own transitions, so music stops between battles. Deltarune Chapter 1 also runs its battle character-box script natively. [PR #88](https://github.com/zenibako/butterscotch-pocket/pull/88) · [PR #84](https://github.com/zenibako/butterscotch-pocket/pull/84)

## Pocket battle tour

These are average milliseconds per frame over each battle-tour section on the 100 MHz os25 Pocket test builds. The earlier Speed build predates the final backdrop, Asgore and Mettaton EX optimizations. The two latest columns use the combined hardware test build. The frame budget is 33.3 ms.

| Battle | Earlier Speed | Latest Speed | Latest Accuracy |
| --- | ---: | ---: | ---: |
| Froggit | 33.1 | 30.5 | 39.8 |
| Toriel | 33.1 | 30.7 | 41.9 |
| Papyrus | 26.7 | 26.8 | 40.3 |
| Undyne | 32.9 | 33.1 | 50.3 |
| Mettaton EX | 35.8 | 35.5 | 62.0 |
| Asgore | 68.3 | 61.9 | 115.8 |

The Speed tour took **156.4 seconds**, down from **163.1 seconds**. Froggit's backdrop draw went from 6.5 to 3.8 ms per frame and Toriel's from 6.6 to 4.3 ms. Mettaton EX's main darkening fill fell from 2.3 to 1.8 ms per Speed frame in the earlier matched comparison.

Against the previous combined build, the final Asgore update reduced Accuracy frame time from **118.3 to 115.8 ms**, with the framebuffer clear dropping from 8.3 to 7.3 ms. Speed frame time went from **62.7 to 61.9 ms**. These are single-run comparisons. [PR #89](https://github.com/zenibako/butterscotch-pocket/pull/89) · [PR #90](https://github.com/zenibako/butterscotch-pocket/pull/90)

## Installation and Memories

Import the core ZIP in Pocket Sync or extract it into the SD-card root, merging `Cores`, `Assets` and `Platforms`. Existing prepared game data and ordinary saves can be reused. [butterscotch-pocket.zip](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.10/butterscotch-pocket.zip) · [Game-data guide](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.10/GAME-DATA.md)

The runner's Memory format remains at revision 10. The audio loader supports Memories made with the older software mixer. Memories and sleep/wake remain experimental and scene-dependent. Deltarune battle Memories can restore with missing party or enemy sprites. [PR #85](https://github.com/zenibako/butterscotch-pocket/pull/85) · [Issue #61](https://github.com/zenibako/butterscotch-pocket/issues/61)

## Verification and limits

The latest hardware evidence covers the Undertale battle tour in Speed and Accuracy on the combined test core. The regular release candidate passed the full distribution workflow, including both Pocket programs, native tools, plugin and C-reference checks, package validation, and checksums. Physical launch, progress-save, Memory and sleep/wake checks for this exact release package are still pending. [Candidate build](https://github.com/zenibako/butterscotch-pocket/actions/runs/42384950986)

The SDK base `a408ddc1`, runtime `902a8adc`, and GCC 13.2.0 pins carry over from v0.7.9. The experimental 100 MHz os25 runtime has **−0.777 ns worst setup slack** in the slow 85°C corner.
