# v0.7.11 — faster Photoshop Flowey and Snowdin snow room

This release speeds up Undertale's final Photoshop Flowey fight in Speed mode, fixes the very slow Snowdin room with the "WARNING: DOG MARRIAGE" sign, and brings in the latest upstream Butterscotch changes. Undertale v1.08 and experimental Deltarune Chapter 1 remain the supported games.

## Changes since v0.7.10

- Photoshop Flowey's Speed-mode drawing reuses cached sprites, textures and vine rasters, and its idle arm, face and scenery draws run natively. Pipes, vines, attack cues and eye borders keep their artwork, including through camera shake and the intro fade. In Pocket testing, the vine attack went from **16.7 to 26.1** game updates per second and the eye attack from **19.9 to 27.8**. A steady 30 is still the goal. [PR #93](https://github.com/zenibako/butterscotch-pocket/pull/93) · [Issue #94](https://github.com/zenibako/butterscotch-pocket/issues/94)
- The runner groups drawables by depth, reuses friction direction vectors, and skips collision events that are verified to do nothing. These are general changes, not specific to Flowey. [PR #93](https://github.com/zenibako/butterscotch-pocket/pull/93)
- Snowdin's snow-patch room (`room_tundra_snowpuzz`, with the "WARNING: DOG MARRIAGE" sign) no longer crawls. Its snow is now drawn natively, and filled circles are drawn as one shape instead of 24 triangles each. On the Pocket, walking through the room went from **901 ms to 44.5 ms** a frame in Accuracy and **30.8 ms** in Speed. The snow also draws solid again; it used to show white stripes. Circle edges elsewhere can shift by up to a pixel; Waterfall's glowstones lose a dark seam. [PR #101](https://github.com/zenibako/butterscotch-pocket/pull/101) · [Issue #87](https://github.com/zenibako/butterscotch-pocket/issues/87)
- Room tile drawing is faster in general. The tile lookup is reused while a room's tiles are unchanged (about 2 ms a frame per 1,000 tiles in Undertale), and the screen clear is no longer written where the tiles cover it anyway. Pictures are unchanged. [PR #102](https://github.com/zenibako/butterscotch-pocket/pull/102)
- Upstream Butterscotch changes through [`ec4fc0b0`](https://github.com/ButterscotchRunner/Butterscotch/commit/ec4fc0b0): CI fixes and an Illumos build fix, with no change to the Pocket programs. [PR #92](https://github.com/zenibako/butterscotch-pocket/pull/92)

## Installation and Memories

Import the core ZIP in Pocket Sync or extract it into the SD-card root, merging `Cores`, `Assets` and `Platforms`. Existing prepared game data and ordinary saves can be reused; prepared data does not need converting. [butterscotch-pocket.zip](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.11/butterscotch-pocket.zip) · [Game-data guide](https://github.com/zenibako/butterscotch-pocket/releases/download/v0.7.11/GAME-DATA.md)

The runner's Memory format remains at revision 10, and v0.7.10 Memories load. Memories and sleep/wake remain experimental and scene-dependent. Deltarune battle Memories can restore with missing party or enemy sprites. [Issue #61](https://github.com/zenibako/butterscotch-pocket/issues/61)

## Verification and limits

The built-in Pocket benchmarks below ran on an earlier release candidate (`0.7.11-rc.100`, before the Snowdin and tile changes) on the 100 MHz os25 runtime. Times are milliseconds per frame, against the v0.7.9 release candidate on the same Pocket. The frame budget is 33.3 ms.

| Undertale (Accuracy) | v0.7.9 | v0.7.11 |
| --- | ---: | ---: |
| Intro, menu, naming | 32.2 | **30.0** |
| First room | 20.0 | **16.6** |
| Flowey talk | 41.7 | **32.4** |
| Flowey battle (640×480) | 50.4 | **38.6** |
| Whole run, 2,600 frames | 94.7 s | **77.0 s** |

| Deltarune Chapter 1 (Accuracy) | v0.7.9 | v0.7.11 |
| --- | ---: | ---: |
| Opening text | 38.7 | **35.3** |
| Character creation | 134.2 | **130.1** |
| Town yard | 26.6 | 26.8 |
| Field (640×480) | 79.5 | **75.5** |
| Battle: menu and attack | 99.3 | **85.8** |
| Battle: dodging | 124.5 | **112.3** |
| Battle: next turn | 93.9 | **86.3** |
| Whole run, 3,600 frames | 226.0 s | **211.0 s** |

| Snowdin snow room (focused benchmark) | Before | Accuracy | Speed |
| --- | ---: | ---: | ---: |
| Standing, snow off screen | 877 | **24.3** | **24.3** |
| Standing near the snow | 883 | **28.0** | **24.7** |
| Walking through the snow | 901 | **40.3** | **30.8** |

These are single runs, and most of the main-benchmark gain came in v0.7.10. The Photoshop Flowey figures come from the focused benchmarks in PR #93, and the snow-room figures from the `--bench-snow` benchmarks in PRs #101 and #102. CI passed on the release code, including both Pocket programs and the distribution workflow ([run](https://github.com/zenibako/butterscotch-pocket/actions/runs/43144669253)); the publish workflow repeats the complete distribution build before drafting. Physical launch, progress-save, Memory and sleep/wake checks for this exact release package have not been run.

Other heavy scenes still run below full speed, including some Snowdin rooms and the Asgore, Mettaton EX and Undyne battles. [Issue #87](https://github.com/zenibako/butterscotch-pocket/issues/87) · [#81](https://github.com/zenibako/butterscotch-pocket/issues/81) · [#82](https://github.com/zenibako/butterscotch-pocket/issues/82) · [#83](https://github.com/zenibako/butterscotch-pocket/issues/83)

The SDK base `a408ddc1`, runtime `902a8adc`, and GCC 13.2.0 pins carry over from v0.7.10. The experimental 100 MHz os25 runtime has **−0.777 ns worst setup slack** in the slow 85°C corner.
